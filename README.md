# Mouse Cochlea Collection Bench

An interactive 3D practice bench for the mouse inner ear protocol in Demirhan & Coate, *JoVE* (2025), e67647. It runs in the browser: pick the right tool, then work on whatever is glowing, step by step from collection to cryosections.

**Open the simulation:** use the GitHub Pages link in this repository's About section.

## Modules

| Module | Protocol sections | What you do |
|---|---|---|
| Embryonic to P5 | 1–2 | Midline cuts, clearing soft tissue, fixation in 4% PFA, freeing the soft inner ear capsule |
| P6 and older | 3 | Midline cuts, popping out the temporal bone, removing the stapes, opening the round window and apex, PFA flush, post-fix, EDTA decalcification |
| Embed and section | 4–5 | Sucrose cryoprotection, OCT, orienting the cochlea in the cryomold, snap-freezing, mounting on the cryostat, trimming and collecting 12 µm mid-modiolar sections |

## How to use

- Pick a tool from the tray (scissors, forceps, hand, pipette, pencil, slide), then click or drag on the glowing target.
- **Show me** demonstrates the current step. **Play the whole demo** runs a module from start to finish.
- Click any step in the list to jump to it, even while the demo is playing.
- Use **View** (or right-drag) to turn the scene, and scroll or pinch to zoom.
- Wrong tools, cuts off the midline and touching soft tissue that shouldn't be touched are flagged as slips.

Works in current desktop and mobile browsers with WebGL 2. Nothing to install.

## About the model

The anatomy is a stylised model. Colours and textures are matched to the protocol video, but shapes and sizes are not to scale, and solution colours only tell containers apart. This is a practice aid for learning the order and handling of each step. It is not a substitute for supervised training under an approved animal protocol.

## Protocol

Demirhan, M.A., Coate, T.M. Cryosectioning and Immunostaining Mouse Inner Ear Tissue: From Embryonic to Adult Stages. *J. Vis. Exp.* (218), e67647 (2025). [doi:10.3791/67647](https://doi.org/10.3791/67647)

The full protocol text and video are on JoVE at the link above. They are not included in this repository.
